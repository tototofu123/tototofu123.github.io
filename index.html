Projects

Public repos on GitHub. List checked on 28 November 2026.

openhere

Small tray tool for Windows that moves each new window to whichever screen the mouse is on. Made because new windows kept opening on the wrong monitor. It is a single AutoHotkey file that runs as it is.

Code: github.com/tototofu123/openhere

hk-bus-fetch

Page that uses KMB data and location to show when the next buses are actually coming.

Code: github.com/tototofu123/hk-bus-fetch

CypherLabEncryption

Built while learning about encryption. A few common methods can be tried to see what happens to a message when it is encrypted, and each method has a short explanation next to it.

Code: github.com/tototofu123/CypherLabEncryption

music-shuffler

Small web page that shuffles a playlist in a way that brings back songs that had been forgotten in there.

Code: github.com/tototofu123/music-shuffler and you can try it at tototofu123.github.io/music-shuffler

inclusive-tourism-decision-platform

Built solo for a hackathon, this project helps people plan trips around accessibility needs, starting with Kowloon to keep the scope workable.

Code: github.com/tototofu123/inclusive-tourism-decision-platform

perihel

Perihel is the project with the most time spent on it. Hold down Right Ctrl and talk, and it writes down what was said, with everything kept on the computer itself. It also saves quick thoughts when they pop up and brings them back later when they are useful again. Written in Rust.

Code: github.com/tototofu123/perihel

agent-bus

Local message bus that lets a few different AI agents talk to each other. They can share rooms, see who is around, and hand work off to each other.

Code: github.com/tototofu123/agent-bus

ocr-mcp

Code: github.com/tototofu123/ocr-mcp

mywebsite

stm32

Tank game that runs on an STM32 board. The tank is controlled over WiFi while the board handles the game and draws the display, and AI bots are included for playing alone.

Code: github.com/tototofu123/stm32
